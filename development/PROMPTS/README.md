# Howard AIOS Prompt 管理规范

---

## 目的

所有用于 Howard AIOS 开发的 AI Prompt 必须版本化管理。

确保每个 Prompt：

- 可追溯（谁写的、什么时候写的）
- 可复现（输入输出明确）
- 可改进（有版本记录）
- 有归属（明确适用 Sprint）

---

## 存放规则

### 目录结构

```
development/PROMPTS/
├── README.md              # 本文件（管理规范）
├── PROMPT-001-<名称>.md   # 具体 Prompt 文件
├── PROMPT-002-<名称>.md
└── ...
```

### 文件命名

```
PROMPT-<编号>-<简短名称>.md
```

编号三位数递增：`PROMPT-001`、`PROMPT-002`、`PROMPT-003`

## 管理规则

### 新增 Prompt

1. 确定编号（查看当前最大编号 +1）
2. 按模板创建文件
3. 填写所有必填字段
4. 在本 README 的索引表中添加记录

### 修改 Prompt

1. 更新版本号（v1.0 → v1.1 小改，v1.0 → v2.0 大改）
2. 更新"最后更新"日期
3. 在版本历史中记录变更说明

### 废弃 Prompt

1. 将状态改为"已废弃"
2. 说明废弃原因
3. 如有替代 Prompt，标注替代编号
