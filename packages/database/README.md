# @howard-aios/database

Prisma-based database infrastructure package for Howard AIOS.

## Structure

```
prisma/
  schema.prisma       — Prisma schema definition
  migrations/         — Migration files (generated by prisma migrate)
src/
  client.ts           — Prisma Client singleton (globalThis cached)
  index.ts            — Public exports
  seed.ts             — Database seed script
```

## Commands

| Command                      | Description                        |
| ---------------------------- | ---------------------------------- |
| `pnpm db:generate`           | Generate Prisma Client             |
| `pnpm db:push`               | Push schema to database (dev)      |
| `pnpm db:pull`               | Pull schema from database          |
| `pnpm db:migrate`            | Create & apply migration           |
| `pnpm db:migrate:deploy`     | Apply migrations in production     |
| `pnpm db:seed`               | Run seed script                    |
| `pnpm db:studio`             | Open Prisma Studio (GUI)           |
| `pnpm db:format`             | Format schema.prisma               |

## Environment

Requires `DATABASE_URL` in `.env`:

```
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/howard_aios
```

## Usage

```typescript
import { prisma } from '@howard-aios/database';

// Use Prisma Client
const users = await prisma.user.findMany();
```
